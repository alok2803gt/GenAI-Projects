MU: Does "Buy the Dip, Sell the Run" Actually Work?

5 years of real MU daily data (2021–2026) · 146 single-day moves ≥5% · real historical options pricing via Polygon
Short answer: no clean statistical edge from timing — MU's own baseline win rate is already 53–59%, and every dip/run threshold tested lands inside normal sampling noise around that baseline. MU is up +1,130% over this window. That secular run is doing almost all the work: buying literally any random day would have won 58.6% of the time at a 20-day hold. The "78% win rate after a 10%+ dip" that looks striking in the raw numbers (n=9) has a p=0.21 chance of occurring purely by luck against that same baseline. One real, narrower signal survives scrutiny — MU's implied volatility crushes more after downside moves specifically — but it doesn't hold up as a clean tradeable strategy on its own. The Real Signal: Options-Market Behavior

Real historical MU option prices (Polygon flat-files), not UW — UW's API is live-only for this account's tier.
Implied vol crush, 10 trading days after the trigger
Dip days show real, trend-adjusted IV crush of +6.4% vs baseline's −4.7% (t=2.39, p=0.028) — borderline significant and directionally consistent. Run days show ~0% (p=0.28) — indistinguishable from a normal day. This is the one real, asymmetric pattern found: it mirrors options-positioning behavior found separately in the Hyperscalers-vs-Memory sector rotation research (real puts build on underperformance days, no symmetric calls build on outperformance days).
Short-straddle P&L (% of premium collected)
Despite the real IV-crush signal, actually selling a naked straddle showed no significant P&L edge for dip (p=0.90) or run (p=0.37) days — one real historical event (May 2026: MU kept falling AND vol kept rising, −113% of premium collected) shows the uncapped tail risk that erases the average. A defined-risk structure (credit spread, not naked straddle) would be needed to actually harvest the vol-crush signal — not yet tested.
Methodology: real 5y MU daily OHLCV (yfinance via breakout_research/universe_5y_ohlcv.pkl), all forward returns measured from trigger-day close, Bonferroni correction applied where noted in the significance table, real historical options prices from Polygon's flat-files S3 bucket (us_options_opra/minute_aggs_v1) with Black-Scholes-implied vol computed from actual observed contract prices.
