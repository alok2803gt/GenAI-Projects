Universe & window

112-ticker curated universe (same reference list as this account's breakout-alert research), real daily OHLCV via yfinance for indicators, real Alpaca 1-minute bars for the intraday exit path. Evaluation window is each ticker's most recent ~252 trading days (~1 year, through 2026-08-24); fuller history is used only as warmup so rolling indicators aren't zero-padded at the start.

The two simulated exits, same entries

Blind close: buy the real open, sell the real close, no stop or target. 0.3% trailing stop: same entry, but walked bar-by-bar through the real 1-minute path — peak trails the running high since entry, exit fires the instant price pulls back 0.3% off that peak, falling through to the real close if never triggered. 0.3% is the account's own live Day Trader trailing-stop setting, not a swept parameter. Every indicator is computed strictly as of the prior day's close (no lookahead).

A real data bug lives in the first attempt at this comparison, since fixed. yfinance's daily bars for a handful of tickers (BKNG, CRWD, KLAC, NOW, XLE, XLK, NFLX) carry a per-ticker back-adjustment that's internally consistent with yfinance's own same-day % returns, but doesn't match Alpaca's real intraday price levels — mixing the two sources briefly produced trades with 2,000%+ "returns." Fixed by sourcing both entry and exit from Alpaca alone. The blind-close numbers here are recomputed from Alpaca and match the original yfinance-only version almost exactly (50.49% vs 50.46% win rate), confirming that first report's own findings held up.
Read the sample size before trusting a row. Small-n combinations can still swing on 1-2 outlier trades. Rows below the sample-size filter are dimmed rather than hidden, and every row shows its real n. The more trustworthy region is n ≥ 400–500, where several combinations land at 56–58% win rate / +0.20% avg return under the trailing stop — both meaningfully above the account's own live Day Trader benchmark (50.5% win / +0.137–0.154%/trade), and on a bigger sample than that strategy's own original validation.
