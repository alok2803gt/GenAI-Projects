Day-Trading Strategy Comparison

Four genuinely different intraday strategy archetypes, backtested against real IBKR minute bars on the exact same 820-candidate opportunity set the live scanner would have selected — compared honestly against what's already deployed.

Not starting from zero

The account's live Day Trader config already went through real validation: a 5-year sizing backtest found the original blind-entry design catastrophic, a 1-minute-bar study resolved the ambiguity for real and found confirmation-gate + 0.3% trailing stop flips it to a positive edge (+0.137%/trade, 50.5% win rate), and an ATR-relative confirmation threshold was tested and lost to the flat one. That exact config is live right now (confirmed via /day-trader/status). This project's job was checking whether anything genuinely different beats it — not rediscovering what already exists.

Why each alternative fell short

StrategyReal finding
ORB (both widths)Degrades monotonically as the range widens — 15min beats 30min on every metric. A tighter range is a more selective, information-dense breakout signal, but neither width closes the gap to baseline.
VWAP mean-reversionClean, real loser. These candidates are ATR-selected momentum names — chosen because they're already moving. Betting on reversion against a population selected for the opposite quality fights the selection criteria itself.
Gap-fadeInvestigated further before accepting the positive average. Median return is exactly −1.00% (the stop level) — the typical trade is a real loser. 210/294 (71%) hit the stop; only 70/294 (24%) hit the actual gap-fill target. Removing the single largest winner (CSGP +16.56%, one trade) collapses avg return from +0.070% to +0.014% and total from +20.55% to +3.98%. Outlier-dependent, not a repeatable edge — rejected rather than reported as a false positive.

Honest caveats

All 4 alternatives were tested at a single reasonable parameterization each — unlike the existing strategy's own multi-round validation (sizing → intraday-ambiguity resolution → ATR-relative confirmation test), these weren't tuned across a real parameter grid. The gap to baseline is large enough (especially VWAP reversion's clearly negative edge) that grid-tuning is unlikely to close it, but a more exhaustive pass remains possible if there's appetite for it.
